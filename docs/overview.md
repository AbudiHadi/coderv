# Overview — claude-docs-toolkit

> **Generated by `/docify` on 2026-04-24 from commit `fbb1954`; hand-maintained since — last verified 2026-07-19 against `f8a0314` (v0.10.0).**


## What this is

The **CoderLap Docs Toolkit** — 7 slash commands + 5 hooks for Claude Code that help devs keep clear docs and honest agents without getting tired. This repo is what users `git clone`; a one-liner installer (`curl -fsSL https://skill.coderv.dev/install.sh | bash`) copies the skills into `~/.claude/skills/` where Claude Code discovers them, and wires the hooks into `~/.claude/settings.json`. <!-- src: install.sh -->

Marketing site + docs live in the separate [`coderv-docs`](https://skill.coderv.dev) repo.

## The 7 commands

| Command | Role |
|---|---|
| `/coderv` | The front door — classifies the request and drives the pipeline of the others on one yes. v0.8.0, ADR-007. <!-- src: skills/coderv/SKILL.md --> |
| `/docify` | Once per project — scans the codebase, writes `CLAUDE.md` + reference docs with source citations. <!-- src: skills/docify/SKILL.md --> |
| `/before` | Pre-code checklist — reads docs, checks past decisions, states a plan, waits for approval; writes the grounding receipt + spec checklist. <!-- src: skills/before/SKILL.md --> |
| `/decision` | Log an ADR in 30 seconds while the choice is fresh. <!-- src: skills/decision/SKILL.md --> |
| `/ship` | Pre-commit — auto-updates docs, validates citations, fresh-context reviewer, verification scorecard (approve at 100%). <!-- src: skills/ship/SKILL.md --> |
| `/session` | End-of-session handoff with verbatim state evidence. `/session last` reads the previous one. <!-- src: skills/session/SKILL.md --> |
| `/lint` | Docs health check — contradictions, stale claims, dead references, rot. v0.7.0, ADR-005. <!-- src: skills/lint/SKILL.md --> |

Plus 5 hooks (Claude Code only): `coderv-router` (UserPromptSubmit), `project-context` (SessionStart), and the three v0.8.0 anti-dumb-zone gates — `grounding-gate` (PreToolUse), `compact-rehydrate` (SessionStart/compact), `context-gate` (Stop). The former 4th gate, `codex-review-gate`, was removed in v0.18.0 (ADR-029) — commit review is Claude-native via `/ship`. See [`skills.md`](./skills.md). <!-- src: install.sh -->

## How the installer works

`install.sh` does three things: <!-- src: install.sh:1-100 -->

1. Detects its own repo path via `SCRIPT_DIR`.
2. Copies every folder from `skills/` into the selected host homes (`~/.claude/skills/` by default; `~/.codex/skills/` and `~/.gemini/skills/` with `--codex`/`--gemini`/`--all`), wires the 5 hooks into `~/.claude/settings.json` (Claude target only), and retires machinery removed since (the `RETIRED_GATES` sweep).
3. Appends the marker `<!-- claude-docs-toolkit -->` to each copied `SKILL.md`. This marker is what `--uninstall` looks for — so our skills can be removed cleanly without touching unrelated skills with the same name.

Flags: `--claude` / `--codex` / `--gemini` / `--all` (hosts), `--force` (overwrite), `--uninstall` (remove our skills + unwire hooks).
